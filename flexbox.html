Основы Flexbox

Flexbox — это режим верстки, оптимизированный для проектирования пользовательских интерфейсов. Он работает в одном измерении (строка или столбец).

Полезные свойства

  • display: flex; — включает flex-контейнер.
  • flex-direction — задает основную ось (row/column).
  • justify-content — выравнивание по главной оси.
  • align-items — выравнивание по поперечной оси.
  • gap — отступы между элементами.
  • flex-wrap: wrap; — перенос элементов на новую строку.
