Основы CSS Grid

Grid Layout — это двумерная система сеток. В отличие от Flexbox, она управляет одновременно и строками, и столбцами.

Полезные свойства

  • display: grid; — включает grid-контейнер.
  • grid-template-columns / rows — задает размеры колонок и строк.
  • gap — отступы.
  • grid-template-areas — именованные области для макета.
  • repeat(auto-fit, minmax(250px, 1fr)) — адаптивная сетка.
